# About Keys — Real Estate Website Demo

A premium, responsive real-estate website concept for About Keys, a property brand based in Karnal, Haryana.

> **Demo status:** Frontend prototype only. Property details, prices, contact information, testimonials, and performance claims must be verified by the business before public use. Any illustrative listings must be clearly marked as demo content.

## Proposed stack

- Astro + TypeScript
- Tailwind CSS
- React components only where useful for interactive UI
- Static-first pages for performance and discoverability

## Demo scope

- Premium homepage and brand introduction
- Property listing cards and property detail pages
- Property categories: residential, plots, and commercial (confirm with the business)
- Property walkthrough/video section using approved public content
- WhatsApp enquiry calls to action (number must be provided/verified)
- Links to official Instagram, YouTube, and Facebook profiles
- Responsive mobile navigation and layouts
- Basic SEO metadata and accessible UI

## Not in the initial demo

- Authentication or customer accounts
- Payment processing
- Real-time inventory or booking
- Admin dashboard / CMS
- Production property data integrations

## Development principles

1. Keep the demo separate from all other projects.
2. Do not invent prices, addresses, availability, customer testimonials, awards, or business metrics.
3. Use clearly identified sample data until approved listing details are supplied.
4. Do not deploy or configure paid services without explicit approval.
5. Run build and basic quality checks before sharing the demo.

## Next steps

1. Scaffold the Astro project with TypeScript and Tailwind.
2. Build the responsive homepage and reusable property cards.
3. Add listing/detail routes and enquiry interactions.
4. Review mobile layout, accessibility, SEO metadata, and production build.
5. Show the demo to the business for feedback before discussing production scope.
